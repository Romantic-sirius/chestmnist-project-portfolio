# Portfolio Showcase Bundle

This folder is prepared for web portfolio publishing.

Included:
- comparison_plots: cross-experiment loss/AUC comparison charts
- 4 experiment folders with:
  - config.json
  - final_result.json
  - metrics.csv
  - metrics.json
  - metrics_curve.png
  - report.md
  - gradcam/*.png
  - error_analysis/errors_topk.json and error_*.png

Excluded intentionally:
- model weights (*.pth) to keep bundle lightweight for web upload
